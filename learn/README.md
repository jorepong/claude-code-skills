# learn

**어떤 주제든 1:1 튜터가 옆에 붙어 가르치듯 깊게 학습하게 만드는 스킬.** 가볍게 훑는 것부터 제대로 파고드는 것까지 강도를 조절합니다.

## 어떤 문제를 푸는가

무언가를 물어보면 AI는 보통 **빠르고 효율적인 요약**을 줍니다. 정보 전달로는 충분하지만, 그것으로 *학습*이 되지는 않습니다. 핵심 메커니즘을 스스로 도출하지 못하고, 며칠 뒤면 남지 않습니다.

learn은 그 순간 AI의 정체성을 바꿉니다. 효율적인 어시스턴트가 아니라 **학습자 옆에서 한 걸음씩 함께 걷는 1:1 튜터**로 동작하게 합니다. 그리고 설명을 채팅에 흘려보내는 대신, `~/.claude/learn/<주제>/`에 **설명 문서·연습문제·시각 자료**로 남겨 하나의 학습 아카이브를 쌓습니다.

## 어떻게 동작하는가

**두 개의 학습 트랙**을 주제 성격에 맞춰 고릅니다.

- **개념 학습** — 원리·구조·동작을 이해하는 주제(예: TLS 핸드셰이크, B-tree, 합의 알고리즘). 한 섹션을 한 문서로 깊게 설명하며 핵심 메커니즘을 도출합니다.
- **구현 장악** — 직접 짜며 익히는 게 핵심인 주제(예: 레이트 리미터 구현, 미니 인터프리터). 참조 구현을 지어 가는 과정을 관전 문서로 남기고, 재구성·결함 주입·변형으로 이해를 검증합니다.

**학습 강도를 다이얼처럼 조절**합니다.

- **가볍게** — 짧은 섹션 지도 + 1~3개 섹션의 초점 있는 심층 설명. 깊이는 얕추지 않되 폭을 좁힙니다.
- **무겁게** — 점수 통합 개요 → 항목 선택 → 다중 섹션 심층 → 평가 → 프로필 갱신. 실습형이면 구현 장악까지 포함한 완전판.

**학습자 프로필에 맞춥니다.** `~/.claude/profile/LEARNING_PROFILE.md`를 참조해 설명의 깊이·진입점을 정하고, "이 학습자가 지금 이걸 배워야 하는 정도"로 각 항목에 점수를 매깁니다. (프로필이 없으면 온보딩하지 않고 일반적인 개발자 수준을 기본값으로 삼으며, 점수는 표시하지 않습니다.)

## 쓰는 법

```
/learn [배우고 싶은 주제·개념]
```

- "카프카 컨슈머 그룹 제대로 파고들자" → 무겁게 모드로 개요·심층 문서·평가까지.
- "합의 알고리즘 감만 빠르게 잡자" → 가볍게 모드로 초점 있는 설명만.

## 폴더 구성

- `SKILL.md` — 진입 지침(주제 확정 → 프로필 로드 → 강도 보정 → 트랙 실행 → 평가).
- `references/` — 이 스킬의 품질을 이루는 규율들:
  - `explanation-principles.md` — 튜터 페르소나, 깊이, 학습자 맞춤 설계, 비유, 시각 자료.
  - `concept-learning.md` · `implementation-mastery.md` — 두 트랙의 상세 절차.
  - `notation.md` — 문서 표기 체계. `workspace.md` — 산출물 레이아웃. `profile.md` — 프로필 사용 규율.

> 이 스킬은 개인 프로젝트(CodeLayer)의 학습 엔진을 떼어내 어디서든 쓸 수 있게 일반화한 것입니다.
