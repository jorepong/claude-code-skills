When used by learn, first read [Learn Remotion Runtime](../learn-runtime.md) and use its `remotion.sh still` or `remotion.sh render` wrapper with the topic slug. Render only when the user asks for an exported file.

## General rendering strategy

Render a video using:

```
npx remotion render
```

Full list of options: https://www.remotion.dev/docs/cli/render.md

Render a still using:

```
npx remotion still
```

Full list of options: https://www.remotion.dev/docs/cli/still.md

## Transparent videos

See [Transparent videos](./transparent-videos.md) for rendering out a video with transparency.
