# remotion/ — learn 내장 Remotion 지식

이 폴더는 learn이 독립적으로 사용하는 Remotion 4.0.516 참조 모음이다. 실행 중 다른 스킬이나 그 설치 경로를 읽지 않는다.

- `SKILL.md` — 기능별 로컬 라우터.
- `learn-runtime.md` — learn의 Player·자산·Studio·렌더 실행 규약. 다른 Remotion 문서보다 우선한다.
- `remotion-markup/` — React 마크업, 타이밍, 전환, 미디어, 효과, 3D 작법.
- `remotion-maps/` — 정적 지도, Mapbox·MapLibre·MapTiler·Cesium 작법.
- `remotion-create/`, `remotion-studio/`, `remotion-render/` — 프로젝트·미리보기·내보내기.
- `remotion-captions/`, `remotion-multimedia/`, `remotion-interactivity/` — 자막·미디어 분석·Studio 편집성.
- `remotion-saas/`, `remotion-docs/`, `remotion-upgrade/` — Player·서버 렌더·공식 문서 조회·패키지 업그레이드.

learn 고유 팔레트·낭독 동기화·포스터 계약은 `../animation.md`, 실행 환경 차이는 `learn-runtime.md`가 정본이다.
